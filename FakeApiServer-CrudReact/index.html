FakeApiServer-CrudReact

This React CRUD demo reads and writes employees through a local json-server API at http://localhost:3000, so it has no hosted live version. Run the API and the app locally:

git clone https://github.com/fadyehabamer/react-lab.git
cd "react-lab/FakeApiServer-CrudReact/FakeApiServer app"
npm install
npm run json:server

# in a second terminal, from the same folder you cloned into
cd "react-lab/FakeApiServer-CrudReact/Bootstrap React fake api/react-fakeapi"
npm install
npm run dev
